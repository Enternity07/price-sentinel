## 价格口径

工作台展示最近一次有效提取的网页公开价格。采集失败时保留上次价格，但标为异常，且不计为已到目标。

金额通过有限正数校验；`None`、`NaN`、`Infinity`、负数及零值不会被转换成零元价格。工作台输入和摘要以 Decimal 校验、计算；上游引擎原有浮点存储保持不变，不宣称已对原引擎做全面金额精度改造。

“最近变动”遵循上游 `last_price` 语义：相较最近一次实际变价前的价格，不代表今日、24 小时或首次加入时的涨跌。

提醒模式是互斥选择：所有变化、低于目标价、波动超过百分比。恢复有货提醒默认启用。目标价为严格低于；百分比为相较上次有效检查价、绝对波动严格超过阈值。原始 API 文档的部分描述仍写“original price”，此处以处理器实际比较逻辑为准。

首次采集建立基线，后续变化由原引擎执行规则和通知。通知渠道需在原引擎设置中配置并测试。本改版没有内置邮箱账号、Webhook 密钥或任何默认收件人。

## 历史边界

- 历史由加入监控后引擎保存的变化快照构成，不包含接入前的价格，也不代表每轮检查都有快照。
- 每次接口最多读取所选范围中最近 500 条快照，截断状态通过 API 返回。
- 缺失价格保留为空，图中断开，不补成零、不以插值伪造真实观测。
- 上游旧快照未保存币种，CSV 明确记录这一点；固定规格、地区和币种后再做比较。
- 工作台只处理 `restock_diff` 商品，不展示或删除其它类型的网页监控。

## 部署

原引擎仍通过原命令运行。工作台地址是在服务根地址后追加 `/prices/`。

`compose.price-sentinel.yml` 从本仓库源代码构建，不使用未改造的官方镜像来冒充个人版。默认端口绑定本机 `127.0.0.1:5080`，数据保存在命名卷。

动态网页的浏览器服务、登录状态以及具体电商平台的提取方式，沿用上游设置；通用价格元数据提取不等于已经适配所有购物平台。未设置任何第三方 API Key；价格工作台自身不调用大模型。

## 验收命令

在仓库根目录、已安装依赖的环境执行：

```bash
python -m pytest price_sentinel_tests -q
node --check changedetectionio/static/js/price-sentinel.js
```

单元与接口测试使用上游真实 Flask 应用、真实临时数据存储和 CSRF；接口测试仅替换外部采集排队动作，避免访问真实商品站点。它们验证新增 API，不冒充真实电商的端到端采集测试。

演示路径 `/prices/?demo=1` 为前端只读示例，不写入真实商品、不执行监控、不发送通知。
