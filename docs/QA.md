## 可重跑

在仓库根目录执行：

```powershell
.\.venv\Scripts\python.exe -m pytest price_sentinel_tests -q
node --check changedetectionio/static/js/price-sentinel.js
```

真实采集脚本仅用于独立的本机测试实例，需要显式启用上游的本地地址测试开关。脚本临时启动商品页面，退出时移除它创建的测试商品，不访问真实电商：

```powershell
.\.venv\Scripts\python.exe scripts/smoke_price_sentinel.py --base-url http://127.0.0.1:5080
```
